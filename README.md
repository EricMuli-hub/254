 Eric Muli Personal Website

A full‑featured multimedia platform with RBAC, AI assistant, multi‑language, beliefs, and WhatsApp auto‑reply.

 Features
- **Landing page** with hero and dedication to Faith Kaluki.
- **User authentication** (register/login) with password change.
- **Role‑based access**: admin (only one) can upload resources; others view only.
- **Multimedia sections**: photos, videos, documents (view online, download requires payment).
- **Beliefs**: Bible, Quran, Hindu, Buddhism, etc., with daily verse and AI‑generated verses.
- **AI Assistant** for research on media, books, and beliefs.
- **WhatsApp auto‑reply** numbers: +245713868382, +254753051262.
- **Language switching** (English default).
- **LocalStorage** persistence – no database needed.

 Setup
1. Clone the repository.
2. Open any `.html` file in a browser (use Live Server for best experience).
3. Default admin: `ericmuli` / `admin123`. Change in `config.js`.

 Deployment on GitHub Pages
- Push all files to a repository.
- Enable GitHub Pages from the repository settings.
- The site will be live at `https://<username>.github.io/<repo>/`.

 File Structure
- `index.html` – landing
- `login.html` / `register.html` – auth
- `dashboard.html` – main user interface
- `admin.html` – admin controls
- `style.css` – all styling
- `script.js` – all business logic
- `config.js` – settings
- `README.md` – this file
- `assets/` – (optional) images
